### OpenAI Agents SDK

**What it is:** OpenAI's production-ready agent framework and the official successor to the experimental Swarm project, providing a well-documented path from prototype to deployment with built-in safety guardrails and multi-agent coordination capabilities.

**What's good about it:** The SDK represents a significant maturation of OpenAI's agent offerings, moving from experimental to production-ready with official support, comprehensive documentation, and enterprise-grade features. It includes built-in safety mechanisms, multi-agent coordination patterns, and seamless integration with OpenAI's latest models.

**Pros:**
- Official OpenAI support with long-term maintenance commitment
- Built-in safety guardrails and monitoring capabilities
- Seamless integration with OpenAI's latest models (GPT-5 series)
- Production-ready architecture suitable for enterprise deployment
- Comprehensive documentation and examples

**Cons:**
- Lock-in to OpenAI ecosystem (may limit model flexibility)
- Potentially higher costs for high-volume usage
- Less community-driven innovation compared to fully open-source alternatives
- Learning curve for teams unfamiliar with OpenAI's specific patterns

**Should we...**
- ✅ **Adopt it** — integrate into our stack (strongly recommended)

**Why:** The OpenAI Agents SDK provides the most mature, production-ready path for building AI agents on OpenAI's platform. For our stack, this offers immediate access to enterprise-grade agent capabilities with built-in safety features that would significantly reduce development time and risk. We should adopt it for new agent projects requiring reliable, scalable implementations with official support, while maintaining flexibility to evaluate other frameworks for specific use cases.

### Google ADK 2.0 (Agent Development Kit)

**What it is:** Google's major update to its Agent Development Kit, announced at Google I/O 2026, featuring a shift from hierarchical executor to graph-based execution engine (similar to LangGraph) with sophisticated multi-agent orchestration capabilities including coordinator agents, sub-agent delegation, and fan-out/fan-in patterns.

**What's good about it:** ADK 2.0 represents a substantial evolution in Google's agent framework offerings, moving toward more flexible, production-ready architectures. It includes built-in human-in-the-loop primitives, state persistence, and is part of a broader Google ecosystem that includes Managed Agents API for hosted deployments and the Agent2Agent (A2A) protocol for cross-framework interoperability.

**Pros:**
- Graph-based execution engine enabling complex multi-agent workflows
- Built-in human-in-the-loop and state persistence capabilities
- Seamless integration with Google Cloud, Vertex AI, and Gemini models
- Agent2Agent (A2A) protocol for cross-framework interoperability
- Designed for production-grade enterprise deployments

**Cons:**
- Strong tie to Google Cloud ecosystem (may limit multi-cloud flexibility)
- Potentially steep learning curve for teams unfamiliar with Google's AI stack
- May be overkill for simple agent use cases
- Less community ecosystem compared to fully open-source alternatives like LangGraph

**Should we...**
- ✅ **Adopt it** — integrate into our stack (strongly recommended)

**Why:** Google ADK 2.0 offers powerful capabilities for sophisticated multi-agent systems, particularly valuable if we're already invested in Google Cloud or planning to leverage Gemini models. The graph-based execution model and built-in enterprise features make it suitable for production deployments. We should adopt it for projects requiring complex agent orchestration, especially those that would benefit from Google Cloud integration, while evaluating it alongside OpenAI's SDK for different use cases.

### Abacus.AI Smaug Agentic Models

**What it is:** A family of open-weight LLMs (Smaug Agentic, Flash, and Mini) launched by Abacus.AI specifically designed for enterprise AI agent use cases, released around September 12, 2026.

**What's good about it:** These models are purpose-built for AI agent workflows, offering optimized performance for agent-specific tasks like reasoning, tool use, and multi-step planning. Being open-weight, they provide flexibility for fine-tuning and deployment control while claiming competitive performance with proprietary models.

**Pros:**
- Specifically optimized for AI agent workloads and workflows
- Open-weight licensing allows for customization and deployment flexibility
- Family of models (Agentic, Flash, Mini) for different use cases and resource constraints
- Claims competitive performance with proprietary alternatives
- Designed for enterprise integration and scalability

**Cons:**
- Relatively new model family with limited real-world validation
- Smaller community and ecosystem compared to established models like Llama
- Potential performance gaps in general-purpose tasks vs. agent-specific optimizations
- Limited benchmark data available for independent verification
- May require significant computational resources for full Agentic model

**Should we...**
- 👀 **Watch it** — keep an eye on it, not ready yet but promising

**Why:** The Smaug Agentic models represent an interesting new entry in the open-weight LLM space, specifically targeting AI agent use cases. While promising, they're too new for immediate adoption without more real-world validation and community feedback. We should monitor their development, benchmark performance, and community adoption over the next few months before considering integration into our stack.

### Tabbit AI Browser

**What it is:** A browser designed for both human users and their AI agents, supporting a wide range of models including GPT-5.x, Claude Sonnet and Opus, Gemini, DeepSeek and several others, positioned as a tool for enabling seamless human-AI collaboration in web-based workflows.

**What's good about it:** Tabbit AI addresses the growing need for interfaces that facilitate effective collaboration between humans and AI agents. By being model-agnostic and designed specifically for agent interaction, it aims to create a seamless environment where humans can oversee, guide, and collaborate with AI agents performing web-based tasks.

**Pros:**
- Model-agnostic design supporting multiple LLM providers
- Specifically designed for human-AI agent collaboration
- Enables oversight and guidance of agent web-based activities
- Supports latest models from major providers (GPT-5, Claude, Gemini, DeepSeek)
- Focuses on practical, everyday workflow integration

**Cons:**
- New product with uncertain long-term viability and support
- May face challenges keeping pace with rapid model updates
- Potential privacy and security concerns with agent browsing capabilities
- Limited information available about enterprise features and administration
- May not replace specialized tools for specific agent use cases

**Should we...**
- 👀 **Watch it** — keep an eye on it, not ready yet but promising

**Why:** Tabbit AI represents an interesting development in the human-AI interaction space, addressing a real need for better collaboration interfaces. However, as a new product launched recently, it requires more time to mature, prove its value, and establish reliability. We should monitor its development, user feedback, and feature evolution before considering adoption for our stack, particularly for use cases involving human oversight of agent activities.
