### Figma Specs
**Link:** https://www.figma.com/blog/introducing-figma-specs/
**Type:** Tool
**What it is:** Announced at Figma's first Config India event on October 14–15 and now in open beta on paid plans, Specs is a Markdown-based container that lives on the Figma canvas. You press D (or drop a .md file onto the canvas), and you get a document that can embed frames, FigJam boards, code layers and designs directly inside it. Figma's agent reads and replies to comments in the spec, connectors pull in context from GitHub or Hex, and the finished spec is handed to an external coding agent through Figma's MCP server.
**What's good about it:** It solves a specific structural problem with a specific structural answer. Markdown design documents have been the useful idea of the last six months — an agent reads a rulebook and produces something on-brand — but they arrive with three failures baked in: they're single-player on someone's laptop, their links rot, and they drift away from the work they describe. Specs keeps the text format but binds it to the artifact. A rule can sit next to the frame it governs, and the frame stays live. The agent-as-collaborator detail is the one that matters most: because the Figma agent can read and reply to comments *inside* the spec, the rulebook has a reviewer that isn't the person who wrote it. And the handoff is a link, not a screenshot — copy the spec URL into a coding agent's prompt and it carries the Markdown, the frame references, the diagrams and the Code Connect snippets with it.
**Pros:**
- Text and design occupy the same object, so a spec can never be stale in the way a screenshot in a Notion page is stale. That is a real architectural difference, not a formatting preference.
- The MCP handoff is bidirectional in practice: Figma's own engineers describe updating a spec from their coding agent as they made progress, then having agents generate FigJam diagrams embedded back into the spec for reviewers. The document stays the single source while code moves.
- Connectors (GitHub, Hex) let a spec answer its own open questions — select a question in a PRD, run the analysis through the connector, and the finding lands as a comment where the question was asked.
- Low adoption cost: Markdown in, Markdown out. No new authoring language, no proprietary spec format to learn.

**Cons:**
- It presumes your design lives in Figma and your code lives in a repo Figma can reach. Our actual production surfaces are a React app built from hand-written components and a dark platform UI tuned by hand — the spec would describe work that never passes through the Figma canvas.
- Open beta on paid plans only, with no published plan for how multi-player spec editing resolves conflicts between two people who duplicated the same spec and then diverged.
- Nothing in the feature *enforces* anything. A spec is context, not a gate — an agent can read the rulebook and ignore it, exactly as it can ignore a prompt. The verification layer is still missing.
- Announced at a regional Config event amid a batch of other features; the blog post is the only detailed source and there is no independent hands-on review of the MCP handoff at scale yet.

**Should we...**
- ✅ **Adopt it**

**Why:** The valuable half of this is the format, not the product, and we can take the format today. Our design review process keeps hitting the same wall: the rules that make the Urology Unified Platform look premium — one accent used rarely, type on scale, Inter only in the UI chrome, generous negative space, SVG iconography at consistent optical weight — live in conversation and in Shareef's head, and every new agent session has to be told them again. Figma has just published a credible, well-reasoned answer to where that knowledge should live: written, versioned, multiplayer, adjacent to the artifact, and readable by an agent over MCP. Where it fits: the Unified Platform and the Big Reef Chapter Player are precisely the kind of surfaces that accumulate design law that nobody wrote down. Even without adopting Figma Specs itself, we should adopt the shape — a Markdown design spec per surface, sitting in the repo next to the code, that every agent session is required to read first. Where it doesn't: as a *gate*. Specs has no enforcement, and our brief's whole direction this week is that enforcement is where quality comes from. Adopt the container; build the linter separately.

### Mozaika Design
**Link:** https://github.com/sezabut/mozaika-design
**Type:** Workflow
**What it is:** An MIT-licensed agent skill that forces a coding agent to decode a real product's design system — colour roles, fonts, measured type scale and weights, radii, section layout — lock that spec, build to it, and then screen the result against an anti-slop gate. It pairs with a companion MCP that serves design systems measured from live production DOMs (588 products, 3,873 decoded sections, 548 measured design systems), but the method itself is a folder of Markdown that needs no account.
**What's good about it:** It names the enemy precisely and then proves it with numbers. The README's opening diagnosis is the most accurate one-liner for what we fight: "Centered stack, soft gradient on white, three identical cards, Inter at 400/600, default radius." That is not a mood, it's a *default set* — and the receipts nail why it reads as slop: a fresh agent rebuilding Mercury from the enriched kit reported, unprompted, "weights given, not guessed — used the real 480/420, not 400/600." The measured examples are the sort of thing you cannot get from a screenshot: Linear's hero is 64px at weight 510 with −1.41px tracking on a 300/400/510/590 weight ladder and a 128px section rhythm; Vercel tracks its hero at −3.84px; Stripe's display weight is 300. Across 548 measured systems the weight ladders run 200→900 — which is exactly why an agent's habitual 400/600 reads as template. And the honesty is unusual: the "how it degrades without the MCP" table, the requirement that the agent say "recalled, not measured" rather than silently guess, and the explicit caveat that the three-agents-three-brands test is a documented internal loop, not a third-party benchmark.
**Pros:**
- The QA gate rule is the sharpest design-review discipline I've read this month: *name the one decision that makes it look hand-built, trace everything else to craft rules or a real product, and fix or cut whatever traces to nothing.* That's a falsifiable test for whether a layout has an idea, and it takes ninety seconds to run.
- Measured rather than recalled values are the actual fix for slop at scale. Defaults are what an agent reaches for when it has no data; give it the real 510 and the −1.41px and the default never gets a chance.
- The Frame step (Subject · Audience · Job · Concept · **Signature**, written in one sentence before any code) forces a stated idea up front — the same discipline the DIRECT framework gave us, with a harder check behind it.
- MIT, plain Markdown, no telemetry, works in Claude Code, Cursor, Codex and Gemini CLI; the free MCP tier is real (25 calls a month on a 30-system shelf, unlimited search) and the degraded mode allows hand-decoded kits from two pasted screenshots.

**Cons:**
- The commercial structure is inverted from the marketing: the method is free, the *data* is the product and unlimited measured systems cost a flat subscription. Any serious use is a paid dependency.
- Three stars and no forks as of this morning, created in June, last pushed October 18 — this is one studio's internal method published for reputation, not a tool with a community stress-testing it.
- Its whole purpose is UI and website surfaces built from a screenshot-and-code loop. It has nothing structural to say about print, poster, email or social creative, and the measured corpus skews toward tech product sites — Linear, Mercury, Vercel — which is not our category and, in the case of the Linear/Mercury look, is the very aesthetic we're trying not to imitate.
- Even the README admits the gap: colour *roles* without usage guidance leave agents guessing which colour acts. That's a real hole in a system whose premise is measured precision.

**Should we...**
- ✅ **Adopt it**

**Why:** Because it converts "that looks like AI slop" — a judgement Shareef can make but nobody can rebut — into a traceable audit. The single most useful export from this repo isn't the MCP, it's the gate: two questions asked of every screen before review. What is the one decision that makes this look hand-built? And what does every other element trace to — a real reference, a craft rule, or nothing? On the Urology Unified Platform, where the premium dark surface and single accent are genuinely good decisions that we have never written a rule around, that gate would immediately show the elements that don't trace: the one card with a radius nobody chose, the second accent creeping into a chart, the weight pair left at 400/600 because nobody specified otherwise. On the Big Reef Chapter Player, a light-theme product with real editorial character, it's the same test in the other direction — prove the lightness is a decision and not a default white page. Adopt the gate and the measured-vs-recalled distinction now, by hand, today. The subscription only becomes worth it when the platform work scales up.

### Magnific One + Brand Kit
**Link:** https://www.magnific.com/one
**Type:** Tool
**What it is:** Launched October 8, 2026 by Magnific (formerly Freepik), Magnific One inserts an art-direction stage between the prompt and the image: it interprets the brief, decides a visual treatment, and only then generates. Draft mode returns 4, 8 or 16 alternative compositions for the credit cost of one; Final renders at 2K or 4K with up to five reference images. Brand Kit is the companion system — feed it a website, a brand-guidelines PDF, a few images or a written description, and an agent extracts logo, palette, typography, imagery and tone into an editable kit that then constrains and *checks* every Final generation.
**What's good about it:** The Brand Kit concept is the correct governance primitive, and the checking behaviour is what makes it more than a saved prompt. Per VentureBeat's briefing, the company ran a live demonstration using a Brand Kit built for VentureBeat — and the first generation failed its own brand checks, flagging an off-policy accent colour and an excessively theatrical treatment behind a speaker. That's a small moment but a meaningful one: a tool whose brand layer can say no to its own output is doing something structurally different from a style reference. Draft returning 8 or 16 art directions at the cost of one generation is also the right economic shape for exploration — cheap divergence, then expensive convergence on the direction you chose. Auto Layers splits output into editable layers, and Designer plus Figma/Photoshop plugins keep the finishing work in real tooling rather than in a chat window.
**Pros:**
- Brand Kit turns a static guidelines PDF into a persistent, shareable, *checkable* set of constraints — the missing link between "we have a brand book" and "everyone who generates an asset obeys it."
- Draft/Final separation is an honest reflection of how art direction actually works: pick the direction on cheap thumbnails, then invest in the one you chose. Most tools collapse both decisions into one expensive roll.
- Broad delivery surface: web, desktop, mobile and an MCP endpoint, so image generation can be wired into an agent pipeline rather than living in another app nobody opens.
- A written FAQ and a documented competitor comparison, including the admission that it is not the first brand-kit product — Runway shipped kit functionality with the same name and added agent-based kit creation in September 2026.

**Cons:**
- The company tells two incompatible stories about what it built. In the VentureBeat interview, Magnific's head of product marketing said it is "powered by GPT-Image-2" with "some post training that we've done"; the supplied FAQ states flatly, "No. Nothing was trained." VentureBeat reports that Magnific has not reconciled the two. Whatever the truth, you are buying prompt orchestration around someone else's model, with the dependency and reproducibility costs that implies.
- The quality evidence is the company's own: a private blind-comparison win rate of 68.5%, a private aesthetic benchmark, and a demo conducted by Magnific rather than independent evaluation. No published data on how often the brand checks actually catch deviations.
- Brand Kit works only with Magnific One, not with any other model on the platform — so the governance layer doesn't travel. If you later decide another generator is better, the kit doesn't come with you.
- Credits run 180 for a 2K High generation to 1,000 for a 4K Max, on subscriptions from $14.50/month billed annually — and the launch promotion that made it free to try ran October 8–15, so the first experience anyone has of it now costs money.

**Should we...**
- 👀 **Watch it**

**Why:** Architecturally this is the second product in two days to bet that composition should be planned before it's rendered — the same bet Canva Craft made with its planning-plus-renderer split, judged here yesterday — and that convergence is the signal. Two independent teams deciding the fix for AI imagery is "decide the picture, then draw it" tells you where the industry thinks the problem is. The Brand Kit idea is directly useful to us in principle: residency marketing and Sub-I welcome materials are produced to a strict, repeatable matrix — one accent, Inter and one display face, real faculty photography, a fixed type scale — and a kit that stores those rules and audits each generation against them is the only version of brand governance that survives contact with a busy week. But I would not put our brand into a system whose own technical account of itself doesn't hold together, and whose check-the-output claim has never been tested by anyone outside the company. Watch it. The test that would change my mind is specific: take the Montefiore navy, the paper-off-white, Inter and one photograph, build a kit, generate ten Sub-I announcement cards, and count how many of the ten pass the kit's own checks — and how many of those that pass are actually usable. The gap between those two numbers is the whole product.

### artistic-color-palettes
**Link:** https://github.com/youssef4laa/artistic-color-palettes
**Type:** Tool
**What it is:** An agent skill (Claude Code, Codex, Cursor, Gemini CLI, Copilot, OpenCode — anything that reads SKILL.md) that replaces an agent's default palette with colours that have a real source: Sanzo Wada's *A Dictionary of Color Combinations* (plates 1–348), Heian-era *kasane no irome* layered colour patterns, palettes sampled from public-domain paintings, and editorial palettes from colorcombinations.org. You ask in plain colour words or start from a brand hex; it offers 3–5 candidates as applied mini-layouts in light, dark and greyscale; you pick one; it builds OKLCH ramps, two-tier tokens, colour proportions, measured WCAG 2 and APCA contrast, and a composed (not inverted) dark mode — written out to DESIGN.md, design/palette.json and design/tokens.css.
**What's good about it:** It does the one thing that separates an art-directed palette from a generated one: it starts from an authored source. Wada's plates and Heian layered-silk combinations are worked colour relationships with documented proportions, and the skill refuses to invent them — "It never invents a plate, painting or pattern, and every palette carries its provenance." The defaults it's attacking are named in its own before/after: a typical indigo-to-purple gradient page where the white button label measures 4.47:1, under the 4.5:1 minimum, versus tokens built from Wada plate 229 — golden yellow against deep slate olive — where the same label measures 13.63:1. That's the whole argument in two numbers. The output discipline is also unusually complete for a six-star repo: a *composed* dark mode rather than a mechanical inversion, colour proportions stated as a rule, and Albers' *Interaction of Color* cited as the perceptual basis rather than a mood board.
**Pros:**
- Provenance is the anti-slop mechanism. A palette that traces to plate 229 of a 1933 dictionary has an author and a logic; a palette that traces to "purple and blue look futuristic" has neither, and that difference survives into the layout.
- Runs in the colour vocabulary a human actually uses — "ocean", "coffee", "dark and muted", or "our brand is #2a9d8f, show me real palettes that hold something close" — and stops for a human choice before writing anything.
- Contrast is measured, not assumed, with APCA alongside WCAG 2 — and the fix path (`validate.py --fix`) is automated rather than advisory.
- Licence hygiene is genuinely thorough: code MIT, Wada digitisation by Matt DesLauriers MIT, 1933–34 plates public domain, kasane rows explicitly flagged CC BY-SA 4.0 with attribution, no plate scans reproduced. Someone thought about what they were republishing.

**Cons:**
- Six stars, zero forks, created October 24, its own default branch still at `release/0.1.0`, no releases. Its tested-agent matrix was verified on one macOS machine on one day. It is three days old.
- The `NOASSERTION` licence on GitHub despite an MIT LICENSE file is a real friction for anything institutional — the data files carry mixed licences and a compliance reviewer will notice.
- The provenance rule creates a hard constraint that will occasionally be exactly wrong: a beautiful Wada plate cannot be made to fit Montefiore navy #003da5 if the plate doesn't hold that hue family, and the skill's honesty means it will say so rather than invent a near-match. Good, but it limits where it applies.
- It handles colour only. Typography, layout, motion, copy are explicitly out of scope — and colour is almost never what's actually wrong with a page that looks generated.

**Should we...**
- 👀 **Watch it**

**Why:** The idea is right and the execution is unproven. Our specific colour problem is a discipline problem, not a search problem: the Unified Platform has a single accent and a premium dark ground that work, and the light marketing palette works, and the failure mode is a generated asset arriving with its own idea of navy and its own second accent. A system that grounds palettes in authored sources and measures contrast against real tokens addresses that directly, and the Wada material in particular is genuinely interesting for the residency marketing work — the plates are designed to be used in combination, with proportions specified, which is exactly the discipline a social campaign needs across a series of cards. But three days old, six stars, one machine of testing, and a licence file that conflicts with its own metadata is a Watch, not an Adopt. The concrete thing worth taking now, for free, is the *method*: never choose a colour without naming its source, always show three to five candidates applied in light, dark and greyscale, and always measure contrast on the rendered result rather than trusting the hex.

### Fjord identity — DutchScot
**Link:** https://www.creativeboom.com/work/this-floating-saunas-brand-uses-a-simple-typographic-trick-to-stunning-effect/
**Type:** Idea
**What it is:** London studio DutchScot's identity for Fjord, a floating sauna and cold-water plunge in Sausalito on San Francisco Bay. The wordmark replaces the "o" with a degree symbol — FJ°RD — and the symbol then functions as a freestanding graphic element, as a compact F° monogram for signage, and as the terminal character of a supersized "Saunalito" broken over three lines. A bespoke typeface was commissioned in collaboration with Danish foundry Playtype: chunky, rounded-square, utilitarian. The palette is stark black and white, and photography is black and white and moody.
**What's good about it:** The concept source is the interesting part. Rather than reaching for the sauna category's visual language — soft neutrals, flowing serifs, faces with eyes closed — DutchScot went to the area's industrial past and built something closer to a shipyard than a day spa. That is real art direction: identify the category codes, then find a truthful source outside them. The degree-symbol move works because it is the one thing a sauna is *defined* by — temperature — expressed as a single typographic substitution rather than as a graphic motif. And the system's extension is unusually coherent: 189°F heat paired against 55°F bay water in huge numerals on a poster, a temperature gauge that moves as you scroll on the website, left-hand navigation that echoes thermometer markings, wayfinding in black metal against timber slats, a felted sauna hat labelled FJ°RD. Even the gift tokens are handmade soap in bespoke packaging instead of a plastic card.
**Pros:**
- One decision carries everything. The degree symbol is legible as a wordmark, as an icon, as a monogram and as a decorative character, so the identity scales from a 48-sheet poster to a hat label without a second idea having to be invented for each format.
- The photography direction is a constraint, not a style: black and white, water-level, moody. That is a rule a photographer can be briefed with and a rule an editor can enforce — the difference between an image bank and an image system.
- It proves the counter-position to AI aesthetics without mentioning AI: a wellness brand deliberately avoiding the wellness look, in a category where "soft neutrals and flowing serifs" is now the default template.
- The physical extension is honest — signage, merch, packaging, a tactile gift object. The identity exists in the world, not only in a case-study deck.

**Cons:**
- The single-substitution idea is the kind of move that reads as brilliant once and then invites a hundred bad imitations — an agency swapping one character for a symbol is now on the slop radar, and most versions won't have a reason behind the swap.
- A stark black-and-white system built on a bespoke typeface is expensive to run and unforgiving in low-quality reproduction. Photocopy a program, print on a cheap banner, view it on a bad laptop screen, and industrial black-and-white becomes mud.
- It is a case study, not a method you can lift directly. Nothing is published about how many directions were explored before this one, so the visible confidence may be survivorship.
- Wellness brands that look non-wellness now risk a different sameness. "We rejected the category codes" is itself becoming a category code.

**Should we...**
- ✅ **Adopt it**

**Why:** This is the cleanest recent demonstration of a principle our residency marketing and Sub-I materials keep failing: an identity is one decision executed relentlessly, not six ideas held in tension. Read against Shareef's surfaces — a residency program announcement card, a Sub-I welcome cover, a faculty portrait series — the Fjord system says do the opposite of what our AI-assisted work defaults to. Not five decorative elements arranged on a card, but one honest decision, stated once, then extended into every format the format allows: a mark, a numeral, a rule, a photographic constraint, a piece of wayfinding. The industrial-past sourcing is the transferable move: our category codes are institutional medicine (navy, stock handshake, the building exterior, the smiling clinician) and the way out is not a prettier gradient — it's finding something true about this department that nobody in the category is using. And the degree-symbol substitution is a reminder that a one-character idea is often stronger than a logo system. Where it doesn't transfer: the monochrome austerity. The Unified Platform's premium dark surface and single accent is its own version of restraint, and it should not be pushed toward stark black and white to borrow a look.

### White & Case rebrand — Uncommon Creative Studio
**Link:** https://www.creativeboom.com/work/this-rebrand-ditches-every-law-firm-cliche-as-white-case-loses-the-navy-blue/
**Type:** Idea
**What it is:** Uncommon Creative Studio's identity for White & Case, the global law firm's first rebrand in 13 years. Navy is replaced with "Catalyst Blue," an electric shade. The logo is drawn from the inscriptions of Trajan's Column and Roman stone carving — a tightly stacked lockup with diagonal cuts slicing through letters such as the W so they appear to lean forward — and the ampersand is reworked as a standalone monogram that works as a lapel pin or a marble lobby sculpture. Kinetic headline serifs carry the system, and an "Energy Studio" proprietary tool stretches parts of photographs into sharp streaks of colour so that a volcano, skyline or wind farm dissolves into lines of data.
**What's good about it:** The strategy is articulate and the design obeys it. The concept is "complexity as a catalyst" — the firm is positioned for polycrisis, and the visual language is deliberately forward-leaning, electric and kinetic rather than stable and sedate. The font choice is the strongest single decision: Trajan's Column is the most authoritative stone letterform in the Western canon, and cutting a *kinetic* interpretation of it — rather than a literal revival — gives the mark both permanence and motion. Uncommon's global chief design officer names the problem with precision: "The legal sector is drowning in navy blue slabs, borrowing from tired financial and tech clichés, and safe choices." That is an accurate description of what happens when design decisions are made by default rather than by a person. Building the ampersand as a standalone monogram that survives at lapel-pin scale *and* as a lobby sculpture is disciplined system thinking — one glyph doing the work of a whole identity.
**Pros:**
- Category codes named and subverted on purpose. The firm knows exactly which clichés it is refusing, and says so — which is the difference between a bold identity and a random one.
- Trajan-derived rather than Trajan-quoted: permanence supplied by the source, momentum supplied by the cut. That's how you use design history instead of borrowing it.
- The single-glyph monogram is a genuinely useful system component — it scales to a pin, a screen, a building, and it means the identity has a shorthand that isn't just the wordmark repeated.
- It's a real, huge, unglamorous client (legal, 125 years old, intensely conservative) — evidence that the premium direction survives contact with the most risk-averse stakeholder type.

**Cons:**
- The "Energy Studio" is exactly the kind of proprietary image effect that hardens into a house look within a year — data streaks across everything, applied to stock imagery until every asset reads as an Uncommon template. The identity's own risk is that its most copyable element is its least meaningful one.
- Catalyst Blue against black kinetic type is a high-voltage combination that reads as confident at brand-film scale and will fight for legibility in dense, small-format contexts — a pitch deck, a footnote, a form. Nothing in the case study shows it under stress.
- Kinetic serifs sliced by diagonals are fashionably of the moment; the leaning-W construction is memorable but will date faster than the ampersand, which is genuinely timeless.
- This is one case study of an extremely well-funded engagement. There's no published account of the motion system's performance in digital product surfaces, which is where most of a firm's daily brand contact actually happens.

**Should we...**
- 👀 **Watch it**

**Why:** Worth studying, not worth copying. The lesson I want Shareef to take is the first half — that naming your category's codes out loud, in the brief, is the single highest-value move in art direction, and that "navy blue slabs borrowed from financial and tech clichés" is a sentence every health-system department could honestly apply to itself. Our version of that sentence exists and we've never written it down. But the second half is the trap: the Energy Studio is a *proprietary effect*, and effects are what slop is made of. It starts as one firm's signature and becomes, within a year, a template in a Canva pack. That's the same arc as the Apple Music mineral-oil ripples we flagged on the 24th — a physically derived idea that becomes a filter that does the thinking for you. Where it could honestly help: the residency marketing campaign has never had a category analysis, and a one-page "here are the six things every residency program does" — stock handshake, building exterior, smiling clinician, navy and teal, generic serif, graduation cap — would constrain the creative far more usefully than any new tool. Where it doesn't: the kinetic slicing, the electric blue, the leaning W. Those belong to a law firm with a polycrisis story to tell, not to a urology department.

## Slop Radar

- **Telling two stories about what you built.** Magnific's interview says "some post training on GPT-2"; its own FAQ says "Nothing was trained." When a tool's technical account of itself doesn't reconcile, the marketing claim is the one to distrust. Ask every vendor to state, in writing, whether weights changed.
- **The proprietary image effect.** Uncommon's data-streak Energy Studio is this week's example of the pattern we flagged with Apple's oil ripples: a distinctive process becomes a filter, the filter becomes a template, the template becomes the look. A filter that does the thinking for you is slop with a provenance story.
- **The Category Codes reflex.** "We rejected the category clichés" is now itself a position that produces recognisable output — no-navy law firms, no-neutrals wellness brands, no-soft-serif institutions. Subverting a code deliberately is art direction; subverting it because the brief said "avoid clichés" is just a different default.
- **The single-glyph substitution.** Fjord's degree symbol works because temperature defines the product. Expect a hundred agency decks where one letter is swapped for a symbol with no reason behind it — a mark is not an idea just because it's clever.
- **"Measured" claims without a measurement.** The good news this week is that Mozaika publishes real numbers (64px at weight 510, −3.84px tracking) and the bad news is that its eleven other competitors will now claim "real design systems" while serving screenshots. Insist on the number, not the adjective.

## Overall Assessment

The week's centre of gravity has clarified, and it is uncomfortable for anyone selling generation: the quality work is all happening in **specification and audit**, not in the model. Figma Specs makes the design rulebook a shared, live, agent-readable object; Mozaika makes the audit a two-question test — what's the one decision that makes this hand-built, and what does everything else trace to; artistic-color-palettes refuses to produce a colour that can't name its source. Even the visual identity work points the same way — Fjord and White & Case are both stories about *one decision stated precisely and extended everywhere*, which is what a specification is in human form. Meanwhile the tool that got the most press this cycle, Magnific One, is valuable for its brand-checking layer rather than its generator, and the generator's provenance is muddled. The honest counter-current: measurement is easy to fake. A week from now there will be a dozen "measured design system" skills serving recalled values, and the difference will be invisible unless you ask for the numbers. The single highest-leverage move for Shareef this week is to write the Unified Platform's design spec — not a brand book, a working document: the accent rule, the Inter weight ladder with real values rather than 400/600, the icon stroke and optical-correction standard, the radius and spacing scale, the five things this surface never does. Put it in the repo where an agent reads it before touching a component. The reason it's urgent is that Figma, Mozaika and everyone else is converging on the same format this month, and the teams that have the document written will be able to adopt any of them in an afternoon.
