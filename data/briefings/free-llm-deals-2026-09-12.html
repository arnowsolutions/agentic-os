Genuine Second Look — Meta (Two Separate Offers)

Meta Muse — 100M tokens/week free consumer agent

What it is: Meta's personal AI agent, launched Sep 8, 2026. Free up to 100 million tokens per week per user (Zuckerberg's number; Meta's own docs only say "available for free with a usage limit"). Paid tiers Power $20/mo (500M tok/wk) and Maximum $100/mo (3B tok/wk). Powered by Muse Spark 1.3, runs in a per-user Linux VM with a Sentinel approval layer.

How to claim: US only, 18+. muse.ai, the Muse app (iOS/Android), or message it inside WhatsApp. A payment card is required at signup even for the free tier.

Pros

  • Enormous free allowance — reporters deliberately burning compute for an evening still used only ~6% of a week.
  • Real execution surface, not a chatbot: browser, email, calendar, Plaid, OpenTable, Stripe Link payments, per-user VM that keeps working while the app is closed.
  • Genuinely useful for personal ops work Shareef currently does by hand (booking, forms, travel research).

Cons

  • No API. It is a consumer product — you cannot point a cron job or our Hermes agent at it. This is manual-use only.
  • Card required even on free tier; US-only; 18+.
  • Independent tests show poor task completion — a reviewer's Amazon / Domino's / Resy attempts all failed; Muse can technically read the per-user VM.
  • Connected services + Meta's ad-data purposes are a real privacy surface: do not connect Montefiore accounts or work email.

Expires: weekly allowance resets (reported reset date Sep 15); launch terms could tighten as demand scales.

👀 WATCH IT — claim only if Shareef wants a personal-ops agent, never for work data

Why: the token figure is the loudest number in AI this week, which is exactly why it needs the caveat: 100M free tokens that no script can reach is worth $0 to our stack. There is no API path, so it cannot power cron briefs, summaries, or image analysis. Its only real value is as a personal assistant for Shareef's own errands (bookings, forms, household admin), and its reliability is currently poor enough that it is not a substitute for doing those tasks. Given it requires a card on file and connects to sensitive accounts by design, the honest recommendation is: interesting, not urgent, and definitely not connected to anything Montefiore.

Hermes Angle: no integration possible — track as a personal tool for Shareef, not an infrastructure input. If Meta ships a Muse Spark contributor/free API tier later, revisit that separately.
