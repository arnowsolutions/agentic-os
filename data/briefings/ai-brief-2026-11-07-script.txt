AI and Hermes Brief, Saturday, November seventh. One thing matters most today: a small tool that would let our cron jobs stop and wait for you, instead of asking a question and dying.

First, Agent Autoloop. It's a small, dependency-free kernel that turns a command-line agent into a background loop. The feature that matters to us is the zero-cost wait. Right now, when a cron job hits something it shouldn't decide alone (sending a department email, filing to the vault, deploying, spending money), it sends you a message and the run ends. The context dies with it. Your answer comes back into a different session that has to reconstruct everything. Autoloop holds that state in a local database, kills the process, and resumes the same conversation when you answer, even days later, with no tokens spent in the meantime. Hermes is already listed as a supported worker, so there's no new agent layer to build. It's a watch, not an adopt: it needs a newer Node than we run, it has no Telegram channel, and its operator text is still in Chinese. But the pilot is one afternoon on the desktop, and it answers the only question that matters. Does a paused run really resume?

Second, CloneGuard. A small read-only scanner that inspects a repository before you run it, and flags the tricks used in credential-stealing attacks: install hooks, editor auto-tasks, hidden network calls, reads of SSH keys and cloud credentials. This is aimed straight at our worst habit. We find a trending repo, and within minutes someone runs npm install on the server. Four days old and sixteen stars, so it gets a try, not trust. Build it, run it over the repos this brief names, and see whether its flags are worth acting on.

Third, OpenAI's SIP telephony. This is news, not a tool. OpenAI now lets you put its voice model directly on a phone call through a SIP trunk, and our number is already on Twilio, which is the example provider in their docs. That's a real alternative to Vapi for the call-out line: one fewer vendor between the caller and the model, and an accept-or-reject decision we control on every call. But it's infrastructure, not a product. No flow builder, no call logs, no voicemail. The line is staff-only, and it works today. So, no migration. Keep it documented as the exit, so that if Vapi's pricing or terms change, we have a plan instead of an emergency.

One more worth naming: Rerun, a self-hostable app of AI coworkers, each with its own memory, skills and schedule, and a rule to ask before it sends, pays, or deletes anything. The shape is exactly right for our operations work. But its email is Gmail only, with no Outlook or Microsoft Graph, so the best template is useless to us. And it wants six gigabytes of Docker on a disk that's ninety-two percent full. Take the design, not the deployment.

Two things I skipped. A proxy that shares consumer AI subscriptions as API endpoints, which sits on the wrong side of the account-risk line we already crossed once. And a desktop terminal for managing agent panes, which solves a problem you don't have. Neither earns a place in our stack.

So, in order: pilot Autoloop on the desktop with Hermes as the worker. Build CloneGuard and run it. And write down what a SIP migration would take. Autoloop gives cron a memory for the decisions it isn't allowed to make. CloneGuard gives our curiosity a seatbelt. And SIP is the door out of a vendor we don't need to walk through today.

That's the brief. Have a good Saturday, Shareef.
